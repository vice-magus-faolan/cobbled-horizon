# Configuration decisions

These files were generated by a successful Minecraft 26.2 server boot, copied into packwiz, and then changed deliberately. Avoid regenerating them blindly; review diffs when mods update their schemas.

## Geyser and Floodgate

`config/Geyser-Fabric/config.yml` uses `auth-type: floodgate`, disables IP-address logging and metrics, and supplies Cobbled Horizon display text.

Before DatHost deployment:

1. Replace Geyser's UDP port only if DatHost assigns a port other than `19132`.
2. Leave `online-mode=true` in `server.properties`.
3. Let Floodgate generate `config/floodgate/key.pem` on the live instance.
4. Never copy or commit that private key.
5. Test a real Bedrock login rather than relying only on a successful server boot.

The included Floodgate configuration permits optional account linking but does not require it.

## Server-Side Waystones

The checked-in config retains the mod's runtime defaults. Global waystone creation is disabled through LuckPerms, because version 1.3.2 exposes that behavior as a permission rather than a JSON setting.

There is no verified cross-dimensional disable option in `sswaystones.json` for this version. Treat cross-dimensional travel as a known policy gap. Do not claim it is disabled unless a later mod release adds a real switch or acceptance testing establishes a reliable alternative.

## Universal Graves

- Non-owner protection: one real-time hour
- Expiration: 24 real-time hours
- XP restored: 75%
- Items drop when a grave expires

The generous expiry limits loss from outages or cross-play UI trouble while preserving a meaningful XP penalty. Test the grave model and inventory interface from Bedrock before launch.

## ServerCore

Gameplay-affecting features in `config.yml` remain disabled. All entries in `optimizations.yml` that declare imperfect vanilla parity are also disabled initially. Enable them only after a spark profile and targeted regression test justify the change.

## Staged performance candidates

Krypton, Fast Noise with ZConfig, and ScalableLux are not part of the baseline export. Their pinned metadata lives under `staged/mods/`; Fast Noise and ScalableLux configuration lives under `staged/config/`. Promote them only after the activation gates in `candidates.toml` pass.

## Structure generation

- Towns and Towers, Explorify, Hopo Better Mineshaft, and DnT Stronghold Lite retain generated defaults.
- Moog's Structure Lib uses a universal spacing multiplier of `2.0`.
- Structure changes only affect newly generated chunks. Freeze this configuration before Chunky pre-generation.

## squaremap

The checked-in `squaremap/config.yml`:

- disables Nether and End maps
- lowers maximum/default/extra zoom
- enables image compression
- reduces background chunks processed per interval

`web-address` and the internal web-server port remain deployment placeholders. Confirm an HTTP port or supported proxy with DatHost before enabling public access. Avoid a full pre-generated public render if undiscovered geography is meant to remain part of exploration.

## Chunky

The repository does not automatically pre-generate a world. After the seed and all world-generation files are frozen, use Chunky to generate the intended Overworld radius and then capture a spark baseline.
